# Xride Airdrop Campaign

Welcome to the Xride Airdrop Campaign application! This is a mini app developed to manage and facilitate an airdrop campaign for Xride, including user login, task management, and leaderboards.

## Features

- **User Authentication**: Users can log in via Google or by providing a phone number.
- **Role Selection**: Users can select their role in the Xride ecosystem.
- **Task Management**: View and manage tasks, including inviting friends.
- **Leaderboard**: View top users based on their Xride tokens and completed tasks.
- **Navigation**: Intuitive bottom navigation to access different parts of the application.

## Installation

To get started with this project, clone the repository and install the dependencies:

```bash
git clone https://github.com/XRIDE-official/Airdrop-Campaign.git
cd Airdrop-Campaign
npm install

Usage

To run the development server, use:

bash

This will start the app and open it in your default web browser.
